    🍎 Fix microphone on a Mac (step by step)

    1. Use Google Chrome (not Safari) and open http://localhost:5000.
    2. Click the 🔒 / ⓘ icon left of the web address → Microphone → Allow → reload the page.
    3. Open Apple menu → System Settings → Privacy & Security → Microphone → turn Google Chrome ON. Quit Chrome fully (⌘Q) and open it again.
    4. Open System Settings → Sound → Input → choose MacBook Air Microphone, speak, and check the input level moves. Raise the input volume if it is low.
    5. Make sure the Mac is connected to the internet — Chrome sends speech to Google to turn it into text.
    6. For Hindi voices: System Settings → Accessibility → Spoken Content → System voice → Manage Voices… → add a Hindi voice. (Macs usually have no Telugu voice — Saathi still shows Telugu text on screen.)
